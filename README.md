- **SQL:** schema design, aggregations (`AVG`, `MAX`), time-bucketing with `date_trunc`
- **Python:** file I/O, CSV and JSON parsing, PostgreSQL with `psycopg2`
- **Git:** version control, `.gitignore`, remote syncing
